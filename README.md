## Before departure

- [ ] Save transport and accommodation confirmations where everyone who needs them can access them.
- [ ] Check arrival times, check-in instructions, and the first transfer.
- [ ] List which reservations are booked and which are still open.
- [ ] Download the maps or directions you need for offline use.
- [ ] Pack chargers, adapters, and the items specific to your activities.
- [ ] Agree on how the group will record and split shared expenses.
- [ ] Leave room in the schedule for changes and rest.
